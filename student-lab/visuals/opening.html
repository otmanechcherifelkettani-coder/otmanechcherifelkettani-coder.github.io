What an agent is

An agent is a model that picks its next step, uses a tool, reads the result, and repeats until the job is done or it hands over to a human.

Five rules of a good agent

  1. Simplest thing first. Known steps → build a workflow. Agent only when the path depends on the input.
  2. Few tools, hard rules in code. The prompt explains the 50 MAD credit limit; the code enforces it.
  3. Always an exit. A maximum number of steps, then a human.
  4. See every step. Every model call, tool call, cost and time is recorded.
  5. Prove it before it ships. Test cases and a pass bar written before the run; a score before and after each fix.
